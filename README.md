Estudo e projeto em C

Sistema de Gerenciamento de Clientes, Produtos e Vendas em C

Projeto desenvolvido em linguagem C com foco na aplicação de estruturas de dados, alocação dinâmica de memória, manipulação de arquivos binários e geração de relatórios.

O sistema permite o gerenciamento completo de clientes, produtos e vendas por meio de operações CRUD (Create, Read, Update e Delete), além da persistência de dados em arquivos e emissão de relatórios personalizados.

Funcionalidades
Cadastro, consulta, alteração e exclusão de clientes
Cadastro, consulta, alteração e exclusão de produtos
Registro e gerenciamento de vendas
Armazenamento permanente em arquivos binários (.dat)
Alocação dinâmica de memória utilizando malloc e realloc
Busca por chaves únicas (CPF e código de produto)
Geração automática de data e hora das vendas
Relatórios em arquivos texto:
Clientes com mais de X telefones
Produtos com validade expirada
Vendas realizadas em um período específico
Menus interativos via terminal
Conceitos Aplicados
Structs
Ponteiros
Vetores dinâmicos
Manipulação de arquivos (fopen, fread, fwrite, fseek, ftell)
Alocação dinâmica de memória
Modularização por funções
Tratamento de datas
Relacionamento entre entidades (Cliente → Venda ← Produto)
Tecnologias
Linguagem C
Biblioteca padrão da linguagem (stdio.h, stdlib.h, string.h, time.h)
Objetivo

Este projeto foi desenvolvido para consolidar conhecimentos em programação estruturada, gerenciamento de memória, persistência de dados e manipulação de arquivos, simulando um sistema de controle utilizado em ambientes comerciais
